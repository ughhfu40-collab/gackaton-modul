# Сценарий защиты на 3 минуты

**Открытие.** «Модус Пульс» помогает довести обратную связь до результата. Покажем, как три обращения отделов превращаются в одно измеримое изменение рабочего процесса.

1. Выберите **Сотрудник · Продажи**. Откройте **Мои обращения → A-011**. Покажите срок первого ответа. Для демонстрации новой формы нажмите **Новое обращение**, заполните заголовок и описание, выберите «Оперативность», высокий приоритет и отправьте. Покажите номер и автоматическое назначение.
2. Переключитесь на **Координатор обращений**. В очереди найдите A-011 по номеру. Выберите «Ожидает уточнения» и напишите «На каком этапе чаще всего задерживается ответ?». Сохраните. Под сотрудником добавьте ответ в истории. Статус вернётся к рассмотрению.
3. Под координатором откройте **Общие проблемы → P-001**. Здесь уже связаны A-021 и A-022, два добавленных тестовых случая. В поле «Связать обращение» выберите A-011. Счётчик вырастет с двух до трёх.
4. Заполните пилот по данным ниже. Покажите, что проблема имеет своего ответственного и дату проверки. Укажите фактическое значение и вывод, затем выберите «Результат проверен».
5. Нажмите **Сообщить авторам** и отправьте «В тестовом пилоте доля срочных запросов с ответом в срок выросла с 40% до 85%». Вернитесь к сотруднику отдела продаж и откройте A-011. Результат виден в карточке и разделе «Обновления».

| Поле пилота | Тестовый пример |
|---|---|
| Ответственный | Координатор обращений |
| Дата проверки | Через неделю после запуска |
| План | Смежная команда сообщает ожидаемый срок ответа в течение рабочего дня |
| Показатель | Доля срочных запросов, по которым сообщили срок ответа за рабочий день |
| До пилота | 40% |
| Цель | 80% |
| Факт | 85% |
| Вывод | Цель достигнута в тестовом сценарии. Сохраняем правило и повторяем замер через месяц. |

## Запасные проверки для вопросов жюри

- **Маршрут без владельца.** Под сотрудником выберите категорию «Прозрачность результатов». Под координатором откройте фильтр «Без ответственного» и назначьте владельца вручную.
- **Отказ с причиной.** Под сотрудником офиса откройте A-017. Причина отказа видна в карточке. При редактировании другого обращения сервер требует результат для статуса «Отклонено».
- **Права доступа.** Сотрудник отдела продаж и сотрудник закупок видят разные списки. Под администратором доступны правила маршрутизации. Серверные проверки также покрыты автоматическим тестом.
- **Аналитика.** На обзоре видны доля завершённых, среднее время первого ответа, просрочки и распределение по типам. Просроченные заявки открываются через одноимённый фильтр.
- **Языки.** Смените «Русский → Қазақша → English» в верхней панели. Исходные описания и сообщения сохраняются на языке автора.
