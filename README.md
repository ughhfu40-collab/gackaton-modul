# Модус Пульс

Система обратной связи для ГК «Модус Трейд». Сотрудник регистрирует проблему, предложение или благодарность и видит результат. Координатор связывает похожие обращения, назначает пилот и публикует результат авторам. Интерфейс доступен на русском, казахском и английском. Тексты из исходного датасета сохранены на русском, заголовки и категории переведены.

## Запуск полного MVP

Требуется Node.js 22.13 или новее. Зависимости npm, Docker и внешний сервер БД не нужны.

```sh
npm start
```

Откройте http://127.0.0.1:3000. Система создаст SQLite-базу `data/pulse.db` и загрузит демонстрационные обращения при первом запуске. Демо открывается под координатором. В верхней панели можно переключиться на сотрудника отдела, руководителя или администратора. Для отдельной сессии тестовый пароль — `pulse-demo`.

```sh
npm test
```

Для новой демонстрации с чистыми данными запустите сервер с новым путём к базе.

```sh
PULSE_DB_PATH=data/defense.db npm start
```

## Версии

| Версия | Где хранятся изменения | Доступ |
|---|---|---|
| Локальный MVP через `npm start` | SQLite на сервере | Серверные сессии и проверки прав, включая скачивание файлов |
| Браузерное демо на статическом хостинге | В хранилище текущего браузера | Переключение тестовых ролей показывает сценарии, данные синтетические |

Статическую версию можно также запустить через `python3 -m http.server 8080 --directory dist` и открыть http://127.0.0.1:8080. Для демонстрации серверного разграничения доступа используйте `npm start`.
